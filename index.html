LEMON: Equivariant Learning over Attention Maps for Zero-Shot Misbehavior Monitoring on New LLMs

Guy Bar-Shalom1, Mor Geva2, Fabrizio Frasca1,†, Haggai Maron1,3,†
1Technion 2Tel Aviv University 3NVIDIA
†Equal supervision
arXiv Code (coming soon)

TL;DR — Attention maps carry signals of LLM misbehavior, but heads and layers are not aligned across models. We treat these mismatches as symmetries and build LEMON, a monitor that is invariant to them, so LEMON transfers zero-shot to LLMs it has never seen, scoring every token as it is generated.

Motivation and problem

To catch LLM misbehavior (hallucinations, jailbreaks) as it happens, a monitor must be online, scoring the text while it is generated, and lightweight, adding little to the cost of generation. Monitors that read the LLM's own internals (in particular, attention maps, as considered in this paper) typically meet both requirements, but each is trained for one specific LLM, and every newly released LLM needs new annotations in order to train a new monitor.

Ideally, we want a single monitor that transfers zero-shot to unseen LLMs. That is hard: attention maps carry misbehavior signals, but heads with the same role sit at different positions in different models:

Cross-LLM mismatches are symmetries

Heads. A multi-head attention layer concatenates its head outputs and applies an output projection \(\mathbf{W}^{O}\). Permuting the head outputs and the corresponding row blocks of \(\mathbf{W}^{O}\) leaves the layer's output unchanged:

$$\operatorname{MHA}(\mathbf{X}) = \big[\mathbf{A}^{1}\mathbf{V}^{1} \,\|\, \cdots \,\|\, \mathbf{A}^{H}\mathbf{V}^{H}\big]\,\mathbf{W}^{O} = \big[\mathbf{A}^{\textcolor{#ad0000}{\sigma}^{-1}(1)}\mathbf{V}^{\textcolor{#ad0000}{\sigma}^{-1}(1)} \,\|\, \cdots \,\|\, \mathbf{A}^{\textcolor{#ad0000}{\sigma}^{-1}(H)}\mathbf{V}^{\textcolor{#ad0000}{\sigma}^{-1}(H)}\big]\,\textcolor{#ad0000}{\mathbf{P}_\sigma}\mathbf{W}^{O}.$$

Here \(\textcolor{#ad0000}{\mathbf{P}_\sigma}\) is the block-permutation matrix corresponding to the head permutation \(\textcolor{#ad0000}{\sigma} \in \mathcal{S}_H\). So two LLMs can implement the same head in different slots; see the illustration below of this symmetry for a single layer.

Layers. Layers are composed sequentially, so their order matters. Their absolute indices, however, carry no fixed meaning across models of different depths. We model layer relabelings as cyclic shifts \(\pi \in \mathcal{C}_L\), treating them as an approximate symmetry assumption that reduces dependence on absolute layer indices.

Together, an independent head permutation in every layer plus a layer shift form the group \(\mathcal{W} = \mathcal{S}_H \wr \mathcal{C}_L\). The relabeling is \((\ell,h) \mapsto (\pi(\ell),\sigma_\ell(h))\), so the group action is as follows:

$$(\sigma_\ell,\pi) \in \mathcal{S}_H \wr \mathcal{C}_L, \qquad (\sigma_\ell,\pi) \cdot \mathbf{A}^{\ell,h}_{n_1,n_2} = \mathbf{A}^{\pi^{-1}(\ell),\; \sigma_{\pi^{-1}(\ell)}^{-1}(h)}_{n_1,n_2}.$$

LEMON is designed to be invariant to the symmetries formalized above.

Our LEMON architecture

Our architecture, LEMON, is based on a Message Passing Neural Network (MPNN), modifying the update function \(f_{\mathrm{up}}:\mathbb{R}^{L \times H \times d}\to\mathbb{R}^{L \times H \times d}\) to be equivariant to the group \(\mathcal{W}\), where \(d\) is the hidden feature dimension.

Making \(f_{\mathrm{up}}\) equivariant to \(\mathcal{W}\). Building on the characterization of linear \(\mathcal{W}\)-equivariant maps by Wang, Albooyeh, and Ravanbakhsh (NeurIPS 2020), we extend their construction to nonlinear neural networks, yielding a more general class of \(\mathcal{W}\)-equivariant maps. We define \(f_{\mathcal{W}}:\mathbb{R}^{L \times H}\to\mathbb{R}^{L \times H}\) as follows, omitting feature channels for clarity:

$$f_{\mathcal{W}}(\mathbf{A}_{n_1,n_2}) = f_{\mathcal{C}_L}(\mathbf{A}_{n_1,n_2}\mathbf{1}_H)\mathbf{1}_H^{\top} + f_{\mathcal{S}_H}^{\mathrm{siamese}}(\mathbf{A}_{n_1,n_2}),$$ $$\big[f_{\mathcal{S}_H}^{\mathrm{siamese}}(\mathbf{A}_{n_1,n_2})\big]^{\ell} := f_{\mathcal{S}_H}(\mathbf{A}_{n_1,n_2}^{\ell}), \qquad \forall\,\ell \in [L].$$

Here \(\mathbf{1}_H \in \mathbb{R}^{H}\) is the all-ones vector. The functions \(f_{\mathcal{C}_L}:\mathbb{R}^{L}\to\mathbb{R}^{L}\) and \(f_{\mathcal{S}_H}:\mathbb{R}^{H}\to\mathbb{R}^{H}\) can be any functions equivariant to \(\mathcal{C}_L\) and \(\mathcal{S}_H\), respectively, with the same \(f_{\mathcal{S}_H}\) shared across all layers. Adding the two paths gives a \(\mathcal{W}\)-equivariant map; see the illustration of \(f_{\mathcal{W}}\) below.

LEMON is online. Each generated token contributes a new attention row, which adds a node and incoming edges to the graph. Forward-only message passing, causal cross-token attention, and a prediction head that scores tokens independently ensure that \(\hat{y}_n\) depends only on tokens \(m \le n\). LEMON can therefore score tokens as they arrive, with the same predictions as within the completed response. Appending each node and its edges costs linear time in the prefix length.

Results

Setup. We use a Leave-One-Out (LOO) evaluation protocol — we train on five LLMs and test zero-shot on the sixth. The held-out LLM contributes no labels to training or model selection. We repeat this for all six LLMs, training separate monitors for hallucination and jailbreak monitoring; see illustration below.

We consider two tasks: hallucination monitoring and jailbreak monitoring. For hallucination monitoring, we use the RAGTruth dataset and predict hallucinations at the token level as tokens are generated. For jailbreak monitoring, we predict attack success from the prompt alone on RedBench, using a universal GCG suffix across requests and LLMs.

LEMON achieves the highest mean ROC-AUC on both tasks, substantially outperforming baselines that do not explicitly account for layer–head symmetries. These results highlight the value of symmetry-aware architectures for transferring monitors to unseen LLMs.
